## 🛡️ **Adversarial Defense & Anti-Spoofing Strategy**

> *"The syndicates are getting smarter. We proved we're smarter."*

In response to recent coordinated attacks on parametric insurance platforms, GigShield has implemented **advanced adversarial defense mechanisms** to protect our liquidity pool and honest delivery partners.

```
🔴 GPS SPOOFING BLOCKED
🛡️ 7-Layer Verification Active
🤖 AI Fraud Detection Live
💰 Liquidity Pool Secured
```

### 🎯 **1. Differentiating Genuine vs. Spoofed Locations**

Traditional GPS verification is dead. GigShield's new AI/ML architecture uses **behavioral biometrics + environmental correlation** to distinguish honest workers from fraudsters:

| Detection Layer | Genuine Worker Signal | Fraudster Signal |
|-----------------|----------------------|------------------|
| **GPS Movement Pattern** | Micro-movements (10-50m drift) + follows road networks | Perfectly static OR impossible teleportation |
| **Device Sensor Fusion** | Accelerometer matches walking/riding patterns | Flat sensor data (phone on table) |
| **Network Fingerprint** | Cellular tower handoffs consistent with movement | Stuck on single tower OR VPN patterns |
| **Historical Baseline** | Matches 30-day behavioral profile | Deviates >3 standard deviations |
| **Environmental Correlation** | Weather data matches reported location | Weather mismatch (reports rain in dry zone) |

#### **How It Works:**

```
┌─────────────────────────────────────────────────────────────────┐
│                    INPUT: Location Claim                        │
└─────────────────────────────┬───────────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  Layer 1: GPS + Cellular Triangulation                         │
│  • Compare GPS with cell tower triangulation                    │
│  • Mismatch >200m → Flag for review                            │
└─────────────────────────────┬───────────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  Layer 2: Sensor Fusion Analysis                               │
│  • Accelerometer: Walking/riding pattern?                       │
│  • Gyroscope: Natural device rotation?                          │
│  • Magnetometer: Consistent compass bearing?                    │
│  • Battery level: Draining normally?                            │
└─────────────────────────────┬───────────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  Layer 3: AI Behavioral Model                                  │
│  • Compare against 30-day movement baseline                     │
│  • Calculate "suspicion score" (0-100)                         │
│  • Threshold: >85 → Block, 60-85 → Enhanced verification       │
└─────────────────────────────┬───────────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                    OUTPUT: Decision                             │
│  ✅ Genuine → Auto-payout                                      │
│  ⚠️ Suspicious → 2FA + Selfie + Live Location                  │
│  ❌ Fraud → Flag + Block + Alert Admin                         │
└─────────────────────────────────────────────────────────────────┘
```

### 📊 **2. Coordinated Fraud Ring Detection**

GigShield's system doesn't just analyze individuals—it detects **network-level attack patterns**:

#### **Data Points Monitored in Real-Time:**

| Category | Specific Data Points | Purpose |
|----------|---------------------|---------|
| **Network Graph** | Telegram group mentions, WhatsApp forwards, common IP addresses | Identify coordination patterns |
| **Temporal Clustering** | Sudden spike in claims from same zone within 5-minute windows | Detect synchronized attacks |
| **Geospatial Anomaly** | Claims from locations with no reported weather events | Catch spoofed weather claims |
| **Device Fingerprint** | IMEI, device model, OS version, app version correlation | Identify cloned devices |
| **Social Graph** | Shared referral codes, overlapping schedules, common phone prefixes | Map fraud networks |
| **Payout Velocity** | Claims from same bank account/UPI across multiple rider IDs | Identify mule accounts |

#### **Fraud Ring Pattern Recognition:**

```
┌─────────────────────────────────────────────────────────────────┐
│  Pattern 1: Telegram-Coordinated Attack                        │
│  • 500 claims in 10 minutes                                    │
│  • All from "red alert zone"                                   │
│  • Weather data shows clear skies                              │
│  • ACTION: Block entire zone, flag all claims                  │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│  Pattern 2: GPS Spoofing Ring                                  │
│  • 50 devices sharing same cell tower for hours                │
│  • All reporting different "stranded" locations                │
│  • Accelerometer data shows zero movement                      │
│  • ACTION: Require live selfie with timestamped location       │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│  Pattern 3: Mule Account Network                               │
│  • 20+ rider IDs linked to same UPI ID                         │
│  • All purchased plans within same hour                        │
│  • Identical device fingerprints                               │
│  • ACTION: Freeze all accounts, admin review required          │
└─────────────────────────────────────────────────────────────────┘
```

### ⚖️ **3. UX Balance: Protecting Honest Workers**

We don't punish genuine riders for fraudsters' actions. Our system uses **graduated verification** to minimize friction:

#### **Verification Workflow by Risk Level:**

| Risk Level | Suspicion Score | User Experience | Time Impact |
|------------|-----------------|-----------------|-------------|
| **✅ Low** | 0-30 | Instant payout | 0 seconds |
| **⚠️ Medium** | 31-70 | Push notification: "Verify your location" → One-tap "I'm here" with background location | 5 seconds |
| **🔴 High** | 71-85 | Live selfie + current location screenshot | 30 seconds |
| **🚫 Critical** | 86-100 | Video selfie with timestamp + manual admin review | < 2 hours |

## 🚀 **Quick Start**

### 1. Clone and Install

```bash
git clone https://github.com/SubhashreeACC/GigShield.git
cd GigShield

# Install backend
cd backend
npm install

# Install frontend
cd ../frontend
npm install
```

### 2. Setup Database

```bash
# Create database
npx prisma migrate dev --name init

# Add sample data
npx prisma db seed
```

### 3. Start the App

```bash
# Terminal 1 - Backend
cd backend
npm run dev

# Terminal 2 - Frontend
cd frontend
npm start
```

### 4. Open in Browser

```
👉 Frontend: http://localhost:3000
👉 Backend API: http://localhost:5000
```
