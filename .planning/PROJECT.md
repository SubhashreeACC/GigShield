# GigShield Project

## Overview
GigShield is an AI-powered parametric income protection platform for gig delivery workers in India.

## Success Metrics
- Weekly active users (WAU)
- Subscription retention rate (>70%)
- Payout turnaround time (<15 min)
- Trigger accuracy (>90%)

## Locked Decisions
<decisions>
- Architecture: React (Next.js) for frontend and Fastify for backend.
- AI: Python + FastAPI for ML layer.
- Database: PostgreSQL + Prisma.
</decisions>
