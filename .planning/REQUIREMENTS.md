# Requirements

## MVP Scope
- R1: User onboarding via OTP (Clerk)
- R2: Subscription via Razorpay UPI Autopay
- R3: Weather and AQI trigger integrations (OpenWeather, AQI APIs)
- R4: Automated payouts under 15 minutes via Razorpay
- R5: Basic fraud detection (Rule-based)
- R6: Analytics Dashboard (User and Admin)
